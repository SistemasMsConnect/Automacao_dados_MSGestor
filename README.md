## AUTOMAÇÃO MSGESTOR

Quando baixar este código, para poder utilizar ele, será necessário realizar o download de algumas bibliotecas:

** Necessário instalar o selenium
** Necessário instalar o pandas
** Necessário instalar o xlwings
** Necessário instalar o pyopenxl
** Necessário instalar o pyinstaller (caso queira criar um executável)
** Caso queria criar um executável pode instalar o pyinstaller
e então executar o pyinstaller nome_da_aplicação

No código em usuário e em senha, onde contém "#####" substitua pelo login e senha que será utilizado na automação. Ou você pode criar um input para digitar o login e senha direto no prompt da automação.
